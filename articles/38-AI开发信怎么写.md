## AI写开发信的真实水平：差一个喂资料的量级

实测中反复出现同一个规律：直接让 AI"写一封充电桩的开发信"，产出结构完整（主题行、价值主张、CTA 都有）但**全文零具体信息**——没有型号、没有功率、没有认证，署名全是占位符，需要人工重写半小时以上。

但把产品资料喂给 AI 之后（快充功率范围、CE/TUV/UL 认证、接入平台数、覆盖国家、测试中心、年产能），AI 立刻产出有参数、有数据支撑的专业开发信，人工终审十几分钟就能发。

**结论：AI 不替你吹牛，它只转述你喂给它的信息。** 喂资料前后，输出质量差一个量级——这不是模型问题，是使用方法问题。

## 正确的四步工作流

1. **AI 搭骨架**：给角色设定和目标客户画像，让 AI 出结构和话术角度
2. **人工喂弹药**：产品参数、认证、案例数据、差异化卖点（这是你最了解的部分）
3. **AI 重写**：把资料融进初稿，要求具体到型号和数字
4. **人工终审**：核对规格、MOQ、价格、交期**零错误**后才能发出——AI 编造产品参数的事故只需发生一次，客户就永久流失

## 喂什么资料：弹药清单

| 类别 | 具体内容 |
|---|---|
| 产品硬参数 | 型号、核心指标（功率/精度/材质/产能）、适用场景 |
| 认证与合规 | CE/UL/FCC/ISO 等，与目标市场对应的认证 |
| 可验证的数字 | 服务客户数、覆盖国家数、出货量、良品率、交期 |
| 差异化 | 和同行比你的 2–3 个真实优势（不是"质量好价格优"） |
| 客户画像 | 目标公司的行业、规模、可能的应用场景 |

## 开发信提示词模板

```
角色：你是资深外贸业务员，为【公司名】撰写开发信。
产品：【产品名 + 3-5 个硬参数 + 认证】
目标客户：【行业/国家/公司类型/可能的痛点】
要求：
1. 主题行 <8 个词，含具体数字或利益点，不用全大写和感叹号
2. 正文不超过 120 词，前两句让客户知道"你是谁、和他有什么关系"
3. 所有产品信息只能使用我提供的内容，禁止编造
4. 结尾给一个低门槛 CTA（如要目录/样品/报价单）
5. 输出英文正文 + 中文说明（方便我核对）
```

## 三个红线

1. **禁止编造**：AI 生成内容中出现的任何参数、认证、客户案例，人工核对不出来源就删掉
2. **禁止全自动化群发**：未经人工终审的开发信批量发出，翻车成本远高于省下的时间（详见[邮件营销与开发信管理](13-外贸邮件营销与开发信管理.md)的合规部分）
3. **禁止一个模板打所有人**：至少按客户行业分 3–5 套资料包，分别喂给 AI——同一封"泛开发信"的回复率会随 AI 普及持续走低，因为海外买家的收件箱正在被 AI 生成的邮件淹没
