## 寄样是销售动作，也是最容易被忽视的成本项

外贸公司普遍愿意寄样——这是行业惯例，客户要样品不给，基本就没下文。但很少有公司算过这笔账：

一年寄 300 票样品，每票 800 元（样品成本 + 快递 + 打样工时），合计 24 万。这 24 万在账上分散在"销售费用""快递费""原材料"几个科目里，看不出是一笔投入，也就没人管它的回报。

更麻烦的是**没人说得清哪票样品带来了订单**。样品寄出去，业务员说"客户在测试"，三个月后无声无息，也没有人复盘。

关键认知：**寄样不是福利，是一笔有明确回报预期的销售投资。** 投资就要有台账、有额度、有转化率。

## 一笔寄样到底花了多少钱

多数人算寄样成本只算快递费，实际成本项远不止：

| 成本项 | 说明 | 常见遗漏 |
|---|---|---|
| 样品货值 | 按成本价而非售价计（用售价会把成本算虚高） | 用报价单价格算，虚高 3-5 倍 |
| 打样工时 | 非标品要单独打样，占产线时间 | 完全不计 |
| 开模/开版费 | 定制款的前置投入，金额可能过万 | 计入"其他费用"后失忆 |
| 国际快递 | DHL/FedEx/UPS 按重量段跳档，含偏远附加费 | 只按首重估 |
| 报关与商检 | 少量样品也可能需要正式报关 | 忽略 |
| 目的国关税 | 客户拒付关税导致退件，来回双程运费 | 完全没预期 |
| 沟通与跟单工时 | 一票样品平均 3-5 次沟通 | 从不计 |

按这个口径，一票"看起来只要 300 块快递费"的样品，实际成本常在 800-2000 元之间。**只有把这个数算出来，才能定"这票该不该寄"。**

一个可落地的做法：系统里给样品单设"成本合计"字段，样品出库时自动带出货值（成本价）、手工补录快递与打样费，一票样品一张成本卡。月末一拉，寄样总成本一目了然。

## 什么客户值得免费寄样

不是所有客户都值得免费。分层标准建议：

**可以免费寄（公司承担）**：
- 已确认采购需求、正在比价阶段的客户（有明确品类、量、目标价）
- 老客户的新品试样
- 展会 A 类客户，且当场承诺过后续动作

**收样品费、订单返还**：
- 新客户、需求不明确
- 定制款、开模打样
- 高货值样品（单价超过某个阈值，比如 50 美元/件）

**不寄或只寄目录/视频**：
- 只留邮箱、问完价格就消失的
- 同一客户短期内反复索样、从无下单记录
- 索样品类与其主营完全不符（常见于"样品收集型"询盘）

"收样品费 + 首单返还"是行业里最实用的折中：既筛掉了不认真的，又不至于把真客户挡在门外。这条规则要写进报价政策，让业务员有据可依，而不是每次现问老板批不批。

**额度机制**：给每个业务员设月度寄样额度（按金额而非票数），超额度需主管审批。这比"每票都审批"效率高，也比"完全不控"有边界。

## 样品台账要记哪几列

Excel 能记，但必须固定字段，否则三个月后就废了。最小可用字段：

- 样品单号、寄出日期
- 客户名称（关联客户卡片，不是自由文本）
- 样品型号/数量/货值（成本价）
- 快递方式、单号、运费、是否客户到付
- 样品费收取情况（免/收/收后返还）
- 签收日期（可查快递轨迹）
- 客户测试反馈（有/无/内容摘要）
- 关联商机或报价单
- 最终结果（成单/在跟/流失 + 流失原因）

其中最关键的三列，也是 Excel 最容易缺的：**签收日期、测试反馈、关联商机**。没有这三列，台账就只是快递记录，不是销售工具。

系统化的价值在于：样品单从报价单生成、自动关联客户与商机、签收状态可回流、结果字段与订单打通。这样"样品转化率"是算出来的，不是估出来的。

## 从样品单到订单的转化追踪

有了台账，可以算三个指标，它们直接指导寄样政策：

1. **样品转化率** = 成单样品票数 / 总寄样票数。行业差异大，但**自己和自己比**有意义——这季度比上季度掉了，就是筛选标准松了
2. **单票样品平均成本** 与 **单票样品带来的平均毛利**。两个数一对比，就知道免费寄样的边界在哪
3. **反馈率** = 有测试反馈的票数 / 已签收票数。这个指标低，说明跟进断了，不是客户不感兴趣

推进节奏上，样品签收后是关键节点：

- 签收后 **3 天内**必须问测试反馈（问法要具体："XX 型号在您产线上的通过率如何"，而不是"样品收到了吗"）
- 反馈"在测试"的，**7 天后**再跟一次
- 反馈"不合适"的，必须问清不合适在哪（参数/价格/包装），记进流失原因——这是产品改进的一手信息
- 连续两次无任何回复的，转长期培育，不再追加寄样

## 五个高频坑

- **样品当人情送**：业务员为了维护关系随手寄，年底一算几十万没有对应订单。解决靠额度与分层规则，不靠自觉
- **寄了不问结果**：最常见也最浪费。签收跟踪必须是系统任务，不是业务员的记忆
- **样品成本不进货值**：只算快递费，导致"寄样很便宜"的错觉，越寄越多
- **样品与量产不一致**：打样时精工细作，量产换料换工艺，客户收到货投诉"和样品不一样"。样品确认要留样并作为验收标准写进合同附件
- **客户拒付关税退件**：欧洲、南美常见。寄样前明确贸易术语（DDP/DDU）与关税承担方，写进 PI 备注

## 自检清单

- [ ] 每票样品有独立的成本合计（含货值、打样、快递、关税）吗？
- [ ] 是否有明确的免费寄样/收费寄样/不寄的分层规则？
- [ ] 业务员有寄样额度，超额度需审批吗？
- [ ] 样品台账是否记录了签收日期、测试反馈、关联商机？
- [ ] 签收后 3 天跟进测试反馈是系统任务还是靠人记？
- [ ] 能算出样品转化率与单票样品回报吗？
- [ ] 样品是否留样，并作为量产验收标准？
- [ ] 寄样的贸易术语与关税承担方是否在 PI 中写明？
