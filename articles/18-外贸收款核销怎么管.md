收款核销是外贸业务里"最后一公里"的财务问题：外汇到账了，但到的是哪笔订单的钱？是全款还是尾款？扣了银行手续费后对不对得上？用 Excel 记的团队，几乎每个月都要花一两天"对账找钱"。这篇讲清核销管理的正确姿势。

## 一、外贸收款核销难在哪

1. **一笔汇款对应多笔订单**：客户合并付款是常态，到账一笔 USD 汇总金额，背后是 3 张 PI 的尾款；
2. **金额对不齐**：银行中间行扣费、汇率折算差异，导致到账金额与发票金额差几十到几百美元——差多少算"核销完成"需要规则；
3. **多币种并行**：USD/EUR/RMB 收款混在一起，本位币口径的核销更复杂；
4. **业务与财务两张皮**：业务员知道订单进度，财务知道钱到没到，两边对不上就是坏账风险的温床。

## 二、核销管理的标准流程

1. **预挂账**：PI 生成时即建立"应收记录"（客户、币种、金额、账期、款项性质：定金/尾款/样款）；
2. **到账认领**：水单进来后按客户+金额+附言自动匹配候选订单，人工确认认领到具体订单；
3. **差额规则**：设定容差（如单笔 ±50 美元的银行手续费自动核销，超出需审批），避免长期挂"差 1 分钱"的死账；
4. **部分核销**：支持一笔款拆到多张订单、一张订单分多次核销，每次核销留痕；
5. **逾期预警**：账期到期未到账自动预警，超期订单自动冻结出货审批（风控联动）；
6. **核销报表**：按客户/订单/业务员三个维度看应收余额与账龄。

## 三、手工 Excel 与系统核销的差距

| 环节 | Excel 模式 | 系统核销模式 |
|---|---|---|
| 到账匹配 | 人工翻订单逐笔猜 | 按客户+金额自动推荐候选 |
| 手续费差额 | 手工调整，月底一堆对不平 | 容差规则自动处理+留痕 |
| 逾期提醒 | 靠记忆或设日历 | 账龄自动预警，联动出货审批 |
| 业财一致 | 业务、财务各一套账 | 同一数据源，单笔可追溯 |

**判断你的企业需不需要系统核销**：应收笔数超过每月 10 笔、或出现过"钱到了不知道是哪单"超过 3 次，就该上了。

## 四、选型时的核销功能清单

- [ ] 按订单/PI 生成应收计划（分期款项各自独立）
- [ ] 到账自动匹配推荐 + 人工认领
- [ ] 部分核销与拆分核销
- [ ] 银行手续费容差规则
- [ ] 账龄报表与逾期预警
- [ ] 出货审批与应收状态联动
- [ ] 与财务软件对接（凭证自动生成）

## 常见问题

**Q：核销做自动匹配，认错了怎么办？**
成熟做法是"系统推荐+人工确认"：自动匹配只做候选推荐，确认权在人，且每次核销都可回溯撤销留痕。

**Q：外汇管制下的结汇单据和核销是什么关系？**
结汇单据是合规层面的凭证，业务核销是管理层面的"钱货对应"。系统里两者分开管理，但收款记录应同时留结汇凭证编号备查。
