## 一句话答案：看流程稳定度和有没有IT

**业务流程三年内不会大改、公司有能管服务器的人、预算能一次性拿出十几万**——偏买断。

**流程还在变、没有专职 IT、希望按年小额支出、需要厂商持续跟政策更新**——偏年租。

绝大多数中小外贸公司属于后者。原因不复杂：外贸的政策环境（税率、报关规则、退税流程、单证要求）年年有变化，买断制下这些更新往往要另付费，而年租制把它包在订阅费里。**买断买的是"永久使用权"，不是"永久可用"**——这两件事差别很大。

## 两种模式的本质差别：谁负责让系统活着

表面上是付钱方式不同，实质是**运维责任的归属不同**：

| 维度 | 年租（SaaS 订阅） | 买断（永久授权/私有化） |
|---|---|---|
| 系统跑在哪 | 厂商云上 | 你自己的服务器（或托管机房） |
| 谁保证它不宕机 | 厂商（看 SLA 条款） | 你（或你的 IT/外包） |
| 政策与规则更新 | 含在订阅费里，版本自动升级 | 常需另购升级包或按次收费 |
| 数据在哪 | 厂商数据库（要看归属与导出条款） | 你自己的机器 |
| 首次现金压力 | 小 | 大 |
| 长期总支出 | 随年限线性累加 | 前高后低，第七年后通常更省 |
| 退出成本 | 数据导出 + 迁移 | 系统继续用，但没人维护会烂掉 |

所以真正要问的不是"哪个便宜"，而是"**未来五年，谁替我盯着这套系统**"。没有 IT 的公司买断一套重型系统，常见结局是：服务器没人打补丁、版本停在两年前、出了故障只能等原厂排期。

## 一笔五年账：同规模公司两种模式的实际支出

以一家 10 人、有出口退税、单证中等复杂度的外贸公司为例（数字为演示口径，非报价）：

| 项目 | 年租（SaaS） | 买断（私有化） |
|---|---|---|
| 首年：许可/订阅 | 2.0 万 | 8.0 万 |
| 首年：实施与培训 | 1.0 万 | 3.0 万（含部署） |
| 第 2–5 年：订阅或维护 | 2.0 万/年 ×4 = 8.0 万 | 许可额的 12% ≈ 1.0 万/年 ×4 = 4.0 万 |
| 第 2–5 年：服务器/备份/运维 | 0（含在订阅） | 0.5 万/年 ×4 = 2.0 万 |
| **五年合计** | **约 11.0 万** | **约 17.0 万** |

按这组假设，买断要到**第七年前后**才追平年租。这里有两个容易忽略的变量会让平衡点往后推：一是买断的升级包通常要另付费（政策年一改就得买），二是私有化的隐性人力成本（IT 排查、备份验证、测试环境）很少被算进去。

反过来说，如果这家公司系统要用十年、业务稳定不变、本来就有 IT 团队，买断的十年总成本会明显低于年租——**年限越长，买断越有利；变化越快，年租越有利**。

## 买断真正贵在哪：四项持续支出

买断的价格标签只覆盖"许可 + 首次实施"，之后还有四项常年支出：

1. **年度维护费**：行业常见为许可额的 10%–20%/年。这笔钱买的是"出问题能找原厂"和"小版本更新"，不付就意味着出故障自己扛。
2. **大版本升级费**：跨版本升级（比如从 V6 到 V8）通常另收费，且可能需要重新实施和二次开发适配。
3. **硬件与安全**：服务器、备份、异地容灾、等保相关要求。数据在自己手里，安全责任也在自己手里。
4. **定制开发的人力**：私有化系统一旦被定制过，每次升级都要重新适配，这笔账签合同时几乎没人算。

## 年租真正贵在哪：四项隐性风险

年租不是没有代价，四项要提前防：

1. **累计支出无上限**：用户数增加、模块增购、订单量超套餐都会推高年费。五年后回头看，"每年不多"会变成一笔不小的数。
2. **涨价与条款变更**：续约时上调价格、调整套餐结构是常见做法。建议在合同里锁定"续约涨幅上限"。
3. **数据锁定**：客户、订单、单证、跟进记录都在厂商库里。**退订能不能完整导出、导成什么格式、要不要收费**，必须写进合同。
4. **停服风险**：小厂商如果经营不下去，系统会突然消失。选年租要看厂商存续能力，必要时要求数据托管或源码托管条款。

## 四条决策线：对着自己的情况打勾

不确定就逐条对，哪边打勾多往哪边走：

| 判断项 | 打勾 → 偏买断 | 打勾 → 偏年租 |
|---|---|---|
| 计划使用年限 | 8 年以上 | 3–5 年，不确定 |
| 业务流程 | 已稳定，三年内不会重构 | 还在调整，可能换模式 |
| IT 能力 | 有专职 IT 或稳定外包 | 没有，希望零运维 |
| 数据敏感度 | 必须物理留在自己机房（如军工配套、涉密品类） | 云上可接受，只要合同约定归属 |
| 现金流 | 能一次性拿出 10 万以上 | 希望按年小额支出 |
| 定制需求 | 有独特流程必须深度定制 | 用标准功能即可 |

如果出现"流程要定制"又"没有 IT"这种组合，先解决 IT 问题再谈买断，否则一定烂尾。

## 第三条路：私有化部署加年维护

市场上有一种混合模式值得知道：**软件私有化部署（数据在你机器上）+ 按年付维护费（厂商负责升级和排障）**。它把买断的"数据可控"和年租的"有人管"拼在一起，代价是年费通常高于纯 SaaS，首年投入也不低。

适合的场景很具体：数据必须留在境内自有服务器、但公司没有能力独立维护一套 ERP 的中型外贸企业。询价时把这句原话问出来——"私有化部署的年维护费包含哪些升级，跨大版本要不要另付"——能省掉后面很多扯皮。

## 合同里必须写清的五个条款

无论选哪种，这五条不写清楚，后面都要付学费：

1. **用户数与模块边界**：多少个账号、含哪些模块、超出后单价多少、只读账号是否收费。
2. **升级政策**：年租要写"订阅期内所有版本更新免费"；买断要写"含几年内的版本升级，跨版本如何计费"。
3. **数据归属与导出**：数据归甲方所有，终止合作后多少天内可完整导出，格式为可读的结构化文件，导出不加价。
4. **服务响应**：故障分级与响应时限（如"系统不可用 2 小时内响应"），以及是否有赔付条款。
5. **涨价与续约**：年租锁定续约涨幅上限（如不超过 5%/年），避免被单方面调价。

## 常见问题（FAQ）

### 买断制是不是一定比年租划算？

只在"用满七年以上、业务稳定、有 IT 支撑"这三个条件同时成立时才划算。多数中小外贸公司三年内会调整流程或换产品线，此时买断的沉没成本很高。另外买断不等于不用再花钱，年维护费、升级费、服务器成本都要算进 TCO。

### 免费的或很便宜的外贸软件能长期用吗？

取决于你的用途。起步阶段用来验证流程没问题，但涉及出口退税、信用证、多票核销这类强合规场景，免费版往往在精度和留痕上不够，一旦出错代价远高于软件费。免费方案的边界在 [免费外贸管理软件盘点](04-免费外贸ERP盘点.md) 里有逐项说明。

### 年租中途想换系统，数据能带走吗？

能，但取决于合同。签约时就要写明"数据归甲方、可完整导出、格式为 Excel/CSV 等结构化文件"。实操中常见的坑是：客户和订单能导出，但**附件（邮件、单证 PDF、聊天记录）不打包**，这类资产往往比字段更值钱。

### 私有化部署是不是就不用担心数据安全了？

不是。数据放在自己机器上只解决了"谁能访问"，没解决"会不会丢"和"会不会被内部人带走"。备份策略、异地容灾、导出审计、字段级权限同样要做，否则只是把风险从厂商转移到了自己身上。
