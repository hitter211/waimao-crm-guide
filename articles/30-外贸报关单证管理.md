## 一套完整的出口单证清单

一票出口业务从头到尾要过的单证，按流程排：

| 环节 | 单证 | 谁出 |
|---|---|---|
| 接单 | PI（形式发票）、销售合同 | 业务 |
| 生产/备货 | 装箱单（Packing List）、发票（Commercial Invoice） | 单证 |
| 订舱 | 订舱委托（SO）、VGM 申报 | 单证/货代 |
| 报关 | 报关单、申报要素、随附单证 | 单证/报关行 |
| 运输 | 提单（B/L）确认件与正本、运单 | 货代 |
| 结汇 | 商业发票、装箱单、产地证（CO/FORM E/RCEP）、保险单 | 单证 |
| 退税 | 报关单退税联（电子）、增值税发票 | 财务 |

看着是单证员的工作，实际每张单的数据源头都在业务环节：品名和 HS 编码来自订单、件毛体来自装箱数据、金额来自 PI 与最终结算方式。**单证错，多数不是单证员的错，是上游数据就没对齐。**

## 错单的高发点：五个真实场景

**场景一：HS 编码归类错。** 同一款产品换个材质、换个用途就是不同编码，退税率随之不同。业务员图省事沿用"上次那个编码"，海关归类核查时轻则改单延误，重则涉及监管证件补办。

**场景二：申报要素漏填错填。** 海关规范申报要素逐年增多（品牌、型号、材质、成分含量……），漏一项就退单。旺季赶船期，退单重报就是赶不上截关。

**场景三：件毛体与实际不符。** 装箱单是按订单数据估的，实际装柜有偏差，提单确认时才发现对不上。改单要钱要时间，不改报关查验时说不清。

**场景四：单证不一致（单单不符）。** 发票、装箱单、提单、产地证上的品名、数量、金额互相打架。信用证结算时银行直接拒付；T/T 结算时客户清关受阻，投诉先到。

**场景五：修改无痕迹。** 单证在 Excel 和 Word 里传来传去，改了哪版、谁改的、最终版是哪版没人说得清。出问题回溯时只有一群"最终版V3-改(2).docx"。

## 制单环节怎么做才能少错

减少错单的核心思路是**数据源头唯一**：单证不是"重新做"出来的，是从业务数据"生成"出来的。

- **订单数据直接生成单证**：品名、数量、单价、贸易术语、唛头一次录入，发票和装箱单从同一份数据生成，不存在两处录入对不上的问题
- **HS 编码库带申报要素**：常用编码建内部库，每个编码挂好规范申报要素模板，制单时选编码自动带出要素，漏填概率大幅下降
- **件毛体来自装箱数据**：按实际装箱（箱数、毛净重、体积）计算，装柜确认后同步更新，不手估
- **版本管理**：单证确认留痕，提单确认件、修改记录在系统里可追溯，不再靠文件名版本号
- **退单重报有记录**：海关退单原因记进系统，同类问题第二次出现时能主动预防

## 单证与业务数据的对应关系

单证管理的深层价值是让"单单一致、单证一致"变成系统约束而不是人工校对：

1. **PI → 订单 → 单证 → 报关 → 退税** 用同一套业务编号串起来，任何一环的数据可向上追到订单、向下追到退税
2. **金额一致性自动校验**：发票金额 vs 报关金额 vs 收汇金额，差异超阈值提醒（部分差异是正常的，比如运费拆分，但要"看得见的差异"而不是"看不见的错"）
3. **数量一致性自动校验**：装箱单数量 vs 报关数量 vs 提单数量，防止装柜损耗导致的静默不一致
4. **品名一致性**：对外品名（英文）与报关品名（中文+HS）分离管理但双向关联，避免"一个货两个名字"各自演化

## 归档与备案：别等到核查才整理

海关对进出口单证的保存期限有明确要求（一般三年起），退税单证备案同样有期限。等核查通知来了再翻档案，多数公司会发现自己连当期业务是谁跟的都说不清。

建议的归档做法：

- **电子档为主、纸质为辅**：所有单证电子档挂到业务记录下（报关单、发票、提单、产地证、水单），纸质原件指定保管人并登记位置
- **按业务编号归档**：不管按月还是按客户归档，最终都能通过业务编号一键拉出全套单证
- **到期提醒**：备案期限、正本提单退回期限设提醒，不靠人脑记

## 选型检查清单

- [ ] 能否从订单/出运数据直接生成发票、装箱单，避免二次录入？
- [ ] 是否内置 HS 编码与申报要素管理？
- [ ] 件毛体是否按装箱数据自动计算？
- [ ] 单证修改是否有版本留痕？
- [ ] 单证电子档能否挂到业务记录下归档并按业务编号导出？
- [ ] 是否有单单一致（金额/数量）的自动校验？
- [ ] 能否对接报关行数据（报关单状态回流）？
